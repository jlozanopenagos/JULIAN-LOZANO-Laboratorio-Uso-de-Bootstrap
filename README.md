Laboratorio: Uso de Bootstrap - Tarjeta Personal
Objetivo: Crear una tarjeta personal usando Bootstrap, aplicando componentes y
utilidades.
Este laboratorio es individual. Debes investigar en la documentación de Bootstrap
para encontrar las clases necesarias.
